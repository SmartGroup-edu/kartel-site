# Share-card fonts

Source Serif 4 (Regular, SemiBold, Italic), static TrueType, Latin + Cyrillic, from Google Fonts
(`fonts.gstatic.com/s/sourceserif4/v15`). Used only by the share-card renderer
(`app/lib/ogCard.tsx`), which needs TTF/OTF — the site's own WOFF2 files cannot be read by
`next/og`.
